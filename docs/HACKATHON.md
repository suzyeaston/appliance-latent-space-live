# Hackathon: an instrument that fits in a backpack

Work in this public repository, using the working browser prototype as the starting point.
Read AGENTS.md and docs/handoff.md. Keep the original private repository and suzyeastonca unchanged.

1. Launch and listen: play all three examples, adjust the sound, try live edits, use Kill, export a project.
2. Make a short original piece and document what feels good or gets in the way. Keep Basecamp visible in the public build context.
3. Add Web MIDI with explicit connection/permission UI and a working fallback when unavailable. Route MIDI through the same events as the sliders. Never intercept typing in the editor.
4. Add the toaster as another control source after the laptop instrument is reliable.
5. Implement a separate actual AI/model adapter later; preserve clear labels and audition/accept/revert. Never put API keys in the browser.

Definition of a public milestone: tests/build pass, a human has played the piece, Save/Export/Kill work, and the hosted version loads both directly and in WordPress. Update the handoff with actual evidence and remaining limitations.
